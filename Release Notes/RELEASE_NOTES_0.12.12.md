# Isotope 0.12.12

## Large battles
- With fog off, a gas cloud or a smoke grenade no longer freezes the game. On a Colossal map every action used to stall for 8–16 seconds; now the first view takes a fraction of a second and a soldier's move a few milliseconds.
- The first smoke grenade of a fog-off match no longer stalls the screen for over a second.
- The periodic hitch every few dozen actions on the largest maps is half as long.
- Random maps generate faster (Colossal stations: 4.5 s → 2.9 s), and battles load faster.
- Nothing about the rules changes: every map, save and replay comes out exactly as before.

## Holdout
- Defending alone on a random map, your deployment zone sits in the middle of the map, and the preview no longer shows an unused zone 2.
- Wave frequency is a number you type: a wave every 1 to 50 rounds.

## Battle screen
- Gas looks like poison, not gravel: a sickly yellow-green cloud with soft edges and slowly drifting wisps. Smoke stays gray.
- Boarding a shuttle shows its seats as a grid over the shuttle; the driver's seat is amber.
- A soldier who climbs into a borg is selected right away, borg and all, even when a whole group was ordered in.

## Multiplayer
- When a match goes out of sync, the game quietly sends the developers one report per match from each side, so the bug behind it can be fixed. Switch it off under Settings → Gameplay → **Send desync reports**.

**Compatibility:** network protocol 23; all players must use the same release.
