# Isotope 0.14.7.3

## Online multiplayer

- Fixed: continuing a long saved match online dropped everyone with "Connection to the lobby server was lost". The save sent to your friends no longer carries the match's full history (only the host uses it), so a save that sent 57 MB now sends about 1.5 MB.
- Large messages now travel in small pieces, so no message is ever too big for the lobby server again.
- Online games need everyone on 0.14.7.3.
