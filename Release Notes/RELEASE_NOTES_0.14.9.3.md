# Isotope 0.14.9.3

- Added **Save Image** below **Save Replay** in the ESC menu. Download a detailed, high-resolution 2D PNG of the full map, choose its resolution, and include or disable dynamic lighting.
- Random event zone lines are slightly thicker and keep the same number of lines when zooming.
- Tanks can now fire diagonally within their existing firing arc. Target previews and AI use the same rules, including range, action costs, shot limits, obstacles, turret damage, and blast damage.
- Older replays retain their original tank firing rules. Multiplayer players must all update to this version.

**Full changelog:** https://github.com/Broiler2113/mcf-isotope/compare/v0.14.9.2...v0.14.9.3
