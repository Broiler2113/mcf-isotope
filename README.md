# MCF Isotope

Optional dynamic lighting is available in **Options → Display**. It starts off;
when enabled, all map types have a dim, readable ambient level. The map editor also
has a **View → Lighting Preview** toggle. HUD and chat brightness are unaffected.

Generated maps include room fixtures and outdoor lighting appropriate to their
setting, including town streetlights. The editor's **Lighting** palette separates
wall-mounted and freestanding fixtures. Place wall lights on solid walls, rotate
with R, and shoot them to destroy the lamp without removing its wall. Destroying a
generator removes that generator's glow; there is no electrical network.

Lights have individual strengths and ranges: indicators and desk lamps are softer,
room lights cover more space, and streetlights and floodlights reach farther. Fire
is warm, machinery is subtly blue, and lamps and gas are white. Glass transmits light.
Lighting changes appearance only; fog-of-war rules continue to determine visibility.

**Z** toggles multiselect using the existing selection controls. In a passenger menu,
Z still changes seats. The shortcut is rebindable in Options. Engineers use a single
**Build…** button to open their fortification choices.
